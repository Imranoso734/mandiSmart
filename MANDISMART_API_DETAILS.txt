MANDISMART API DETAILS
=======================

System Name
-----------
MandiSmart

Purpose
-------
Ye backend mandi business ko digital banane ke liye design kiya gaya hai. Is mein supplier se aane wala maal, customer sale, customer payment, khata, expenses, aur reports manage hoti hain.

Base URL
--------
/api/v1

Authentication
--------------
Protected endpoints par ye header lazmi hai:
Authorization: Bearer <token>

Roles
-----
OWNER:
- tenant profile manage kar sakta hai
- operator users create/update/delete kar sakta hai
- sari reports dekh sakta hai

OPERATOR:
- customer, supplier, consignment, sale, payment, expense entries kar sakta hai
- field work aur mandi floor operations handle kar sakta hai

- email
- password

## 3) End-to-end business flow

Ye flows poore system ko cross-check karte hain:

### Flow 1: supplier -> consignment -> sale -> payment
- supplier create karo
- consignment create karo
- customer create karo
- sale create karo consignment item ke against
- payment create karo customer ke liye
- customer ledger report verify karo
- sale + payment balance expected ho

### Flow 2: expense + settlement
- consignment pe expense add karo
- commission type/value set karo
- consignment close karo
- supplier settlement report dekho
- commission + expense deduction aur payable amount verify karo

### Flow 3: tenant isolation
- tenant A create karo owner+data
- tenant B create karo owner+data
- tenant A ke token se tenant B data access fail ho
- same phone/email alag tenant par allowed hona chahiye
